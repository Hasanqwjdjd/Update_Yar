# 📱 راهنمای ساخت فایل APK اپلیکیشن «آپدیت‌یار»

این راهنما مرحله‌به‌مرحله توضیح می‌دهد که چطور از پروژه‌ی آماده‌ی Android (پوشه `android/`)، فایل نصبی APK بسازید.

> **✅ اپ کاملاً آفلاین است:** کل رابط کاربری، فونت‌ها و داده‌های نمونه داخل خود APK ذخیره می‌شوند و **هیچ نیازی به اینترنت، سرور یا آدرس وب نیست**. اطلاعات کاربر هم روی خود گوشی (حافظه محلی) ذخیره می‌شود.

---

## 🆕 تغییرات نسخه ۱.۴ (درگاه بدون مرچنت + دسترسی‌های واقعی)

| بخش | قبلاً (۱.۳) | حالا (۱.۴) |
|---|---|---|
| درگاه پرداخت | نیازمند «کد مرچنت زارین‌پال» | درگاه آنلاین دونیتو (donito.me/ehsan2noven) — پول مستقیم به حساب شما، بدون هیچ کد مرچنت |
| جریان خرید | Request/Verify زارین‌پال | باز شدن درگاه در مرورگر → پرداخت → برگشت به اپ → وارد کردن شماره رسید → فعال‌سازی فوری + ثبت رسید |
| دسترسی‌های گوشی | فقط اعلام در آنبوردینگ | درخواست واقعی: اعلان‌ها (اندروید ۱۳+)، صفحه «نصب برنامه‌های ناشناس»، راهنمای «اطلاعات برنامه‌های نصب‌شده» MIUI |
| زمان‌بندی تم | انتخاب می‌شد ولی هیچ اثری نداشت | واقعی: تم تیره خودکار ساعت ۲۰ شب تا ۷ صبح (بررسی هر دقیقه) |
| سورس پروژه در گیت‌هاب | لینک مخزن خصوصی نمایش داده می‌شد | حذف کامل از تمام صفحات (حفاظت از کد) |
| ایمیل پشتیبانی | support@updateyar.ir | updateyarsupport@gmail.com (در همه صفحات) |
| اسکن | در بعضی گوشی‌ها «خطا» | مقاوم‌سازی کامل: هر خطا → برگرداندن همان لیست خوانده‌شده؛ لیست خالی → راهنمای دسترسی |

### پرداخت چطور کار می‌کند؟
1. کاربر «خرید اشتراک» یا «حمایت» را می‌زند → صفحه‌ی درگاه دونیتو در مرورگر گوشی باز می‌شود.
2. کاربر مبلغ را آنلاین پرداخت می‌کند → پول مستقیماً به حساب شما (دونیتو ← بانک شما) می‌رود.
3. کاربر به برنامه برمی‌گردد و شماره رسید/پیگیری درگاه را وارد می‌کند → اشتراک/حمایت فعال و رسید ثبت می‌شود.
بدون وارد کردن شماره رسید، هیچ اشتراکی فعال نمی‌شود؛ پس هیچ پرداخت تقلبی وجود ندارد.

### نکته شیائومی / MIUI
اگر اسکن با پیام «دسترسی به لیست برنامه‌ها داده نشد» مواجه شد:
`تنظیمات گوشی ← برنامه‌ها ← آپدیت‌یار ← سایر دسترسی‌ها ← دریافت اطلاعات برنامه‌های نصب‌شده` را روشن کنید
(دکمه «رفتن به تنظیمات» داخل همین پیام، مستقیم همان‌جا می‌برد).

## ۱. نصب پیش‌نیازها

### گام ۱: نصب Android Studio

1. به آدرس [developer.android.com/studio](https://developer.android.com/studio) بروید.
2. نسخه‌ی Windows (یا مک/لینوکس متناسب با سیستم شما) را دانلود و نصب کنید.
3. حین نصب، همه‌ی گزینه‌های پیش‌فرض را **Next** بزنید (شامل Android SDK و Virtual Device).
4. بعد از نصب، Android Studio را باز کنید و بگذارید کامپوننت‌های اولیه را دانلود کند (چند دقیقه طول می‌کشد).

> حجم دانلود اولیه حدود ۲ تا ۳ گیگابایت است؛ اینترنت پرسرعت توصیه می‌شود.

### گام ۲: بررسی JDK

Android Studio به‌صورت خودکار JDK (نسخه ۱۷ به بالا) دارد و نیازی به نصب جداگانه نیست.

---

## ۲. باز کردن پروژه

1. مخزن گیت‌هاب را **clone** کنید (یا فایل ZIP را دانلود و باز کنید):

```bash
git clone https://github.com/Hasanqwjdjd/Hasan-Vpn.git
```

2. در Android Studio: **File → Open** و پوشه‌ی `android` داخل پروژه را انتخاب کنید
   (یعنی مسیر `Hasan-Vpn/android`).
3. بار اول، Android Studio شروع به **Gradle Sync** می‌کند و وابستگی‌ها را دانلود می‌کند؛ صبر کنید تا کامل شود (پایین پنجره نوار پیشرفت است). اگر خطای SDK گرفت، روی لینک «Install missing SDK» کلیک کنید.

---

## ۲.۵ روش بدون نصب — ساخت APK با GitHub Actions (پیشنهادی) ⚡

اگر نمی‌خواهید Android Studio نصب کنید، بگذارید **سرورهای خود گیت‌هاب** APK را برایتان بسازند — رایگان و بدون هیچ نصبی!

فایل `.github/workflows/build-apk.yml` از قبل در مخزن آماده است. کافیست:

1. وارد مخزن شوید: `github.com/Hasanqwjdjd/Hasan-Vpn`
2. از نوار بالای صفحه، تب **Actions** را باز کنید
3. از منوی سمت چپ روی **Build APK (آپدیت‌یار)** کلیک کنید
4. سمت راست، دکمه‌ی **Run workflow** را بزنید → **Run workflow** (برنچ `main` بماند)
5. ۳ تا ۶ دقیقه صبر کنید تا کار تمام شود (نقطه‌ی سبز ✅ کنار اجرا)
6. روی اجرای تمام‌شده کلیک کنید → پایین صفحه در قسمت **Artifacts** فایل **`updatayar-apk`** را دانلود کنید
7. فایل ZIP دانلودشده را باز کنید — **دو فایل** داخلش است:
   - `app-release.apk` ← **نسخه‌ی نهایی امضادار** (پیشنهادی — برای استفاده شخصی و انتشار در کافه‌بازار/مایکت) ⭐
   - `app-debug.apk` ← نسخه‌ی دیباگ (فقط برای تست)
8. فایل مورد نظر را به گوشی بفرستید و نصب کنید 🎉

> 💡 هر بار که فایل‌های پوشه‌ی `android/` یا `capacitor.config.ts` تغییر کنند و push شود، APK جدید به‌صورت خودکار ساخته می‌شود.
> ⚠️ برای مخازن خصوصی، ماهانه ۲۰۰۰ دقیقه‌ی رایگان دارید (هر ساخت حدود ۴ دقیقه مصرف می‌کند — یعنی حدود ۵۰۰ ساخت در ماه!).

---

## ۳. آپدیت محتوای اپ (پس از تغییر کد)

اپ کاملاً داخل APK ذخیره می‌شود؛ پس اگر کد را تغییر دادید باید مراحل زیر را تکرار کنید:

```bash
bun run build          # ساخت نسخه استاتیک در پوشه out/
npx cap sync android   # کپی اپ به داخل پروژه اندروید
```

سپس در Android Studio دوباره APK بگیرید (یا در تب Actions گیت‌هاب، Run workflow بزنید — همه‌ی این مراحل آنجا خودکار است).

---

## ۴. ساخت APK (روش ساده — Debug)

مناسب تست سریع روی گوشی خودتان:

1. در Android Studio منوی **Build → Build Bundle(s) / APK(s) → Build APK(s)** را بزنید.
2. صبر کنید تا پیام «BUILD SUCCESSFUL» بیاید.
3. از نوتیفیکیشن پایین-راست روی **locate** کلیک کنید تا مسیر فایل باز شود:

```
android/app/build/outputs/apk/debug/app-debug.apk
```

4. همین فایل `app-debug.apk` را به گوشی بفرستید (تلگرام/کابل/…) و نصب کنید. ✅

---

## ۵. APK نهایی امضادار (Release — برای انتشار در کافه‌بازار/مایکت)

✅ **خبر خوب: از نسخه 1.1 به بعد، کلید امضا از قبل ساخته شده و داخل پروژه تنظیم شده است!**

### وضعیت فعلی (آماده و تنظیم‌شده)

| مورد | مقدار |
|------|-------|
| فایل کلید | `android/app/updatayar-release.keystore` (داخل مخزن خصوصی) |
| نام مستعار (Alias) | `updatayar` |
| رمز کلید و کی‌استور | `Updatayar@1404` |
| اعتبار کلید | ۱۰٬۰۰۰ روز (حدود ۲۷ سال) |
| امضای نسخه Release | در `android/app/build.gradle` تنظیم شده ✅ |

یعنی:

- **با روش GitHub Actions** (بخش ۲.۵): علاوه بر APK دیباگ، فایل `app-release.apk` امضادار هم به‌صورت خودکار در همان Artifact ساخته می‌شود — هیچ کار اضافه‌ای لازم نیست.
- **با Android Studio**: فقط **Build → Build APK(s)** را بزنید؛ هر دو نسخه (debug و release امضادار) ساخته می‌شود.

فایل نهایی و قابل انتشار در این مسیر ساخته می‌شود:

```
android/app/build/outputs/apk/release/app-release.apk
```

### ⚠️ نکته حیاتی درباره کلید امضا

- فایل `updatayar-release.keystore` را **هرگز گم نکنید** و رمز آن (`Updatayar@1404`) را جای امن ذخیره کنید!
- بدون این کلید، هیچ‌وقت نمی‌توانید آپدیت رسمی برای نسخه‌های قبلی منتشر کنید (کافه‌بازار و گوشی‌ها امضا را چک می‌کنند).
- اگر مخزن گیت‌هاب را عمومی (Public) کردید، اول کلید را از مخزن حذف و به GitHub Secrets منتقل کنید.
- برای انتقال به سیستم شخصی: فایل `android/app/updatayar-release.keystore` را کپی و نگهداری کنید.

### نصب نسخه Release روی گوشی

اگر قبلاً نسخه Debug را نصب کرده‌اید، هنگام نصب نسخه Release پیام «برنامه نصب نشد» می‌بینید (امضای دو نسخه متفاوت است). راه‌حل ساده:

1. نسخه قبلی را از گوشی حذف (Uninstall) کنید.
2. نسخه Release را نصب کنید. از این به بعد همه آپدیت‌های امضادار بدون حذف، مستقیم روی همین نسخه نصب می‌شوند. ✅

> 💡 برای انتشار در کافه‌بازار، فایل AAB بهتر است: در Android Studio از منوی **Build → Generate Signed Bundle / APK → Android App Bundle** استفاده کنید (همان کلید بالا).

---

## ۶. تغییر شماره نسخه برای آپدیت‌های بعدی

هر بار که می‌خواهید نسخه‌ی جدید منتشر کنید، در `android/app/build.gradle`:

```gradle
versionCode 2        // ← یکی بیشتر کنید (عدد صحیح)
versionName "1.1"    // ← نسخه‌ی نمایشی به کاربر
```

---

## ۷. سوالات پرتکرار

**❓ موقع نصب APK روی گوشی، پیام «نصب مسدود شد» می‌آید**
در تنظیمات گوشی: Security → Install unknown apps → اجازه‌ی نصب به برنامه‌ای که فایل را باهاش منتقل کردید بدهید.

**❓ اپ باز می‌شود ولی صفحه سفید است**
محتوای داخل APK قدیمی است یا sync انجام نشده. دستورات بخش ۳ را اجرا کنید و دوباره APK بسازید.

**❓ خطای Gradle Sync (دانلود نمی‌شود)**
برای تحریم‌ها ممکن است نیاز به تغییر پروکسی یا استفاده از mirror باشد. در تنظیمات Android Studio (Settings → HTTP Proxy) پروکسی را تنظیم کنید یا از ابزارهایی مثل رادار/شکن استفاده کنید.

**❓ مجوز REQUEST_INSTALL_PACKAGES برای چیست؟**
این مجوز به اپ اجازه می‌دهد بسته‌های به‌روزرسانی را نصب کند (در صفحه‌ی آنبوردینگ اپ هم توضیح داده شده). اگر فعلاً نمی‌خواهید، خط مربوطه را از `android/app/src/main/AndroidManifest.xml` حذف کنید.
