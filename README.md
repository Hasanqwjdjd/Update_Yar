# 🚀 آپدیت‌یار | UpdateYar

وب‌اپلیکیشن فارسی موبایل‌فرست مدیریت به‌روزرسانی برنامه‌ها — با رابط کاربری راست‌به‌چپ، فونت وزیرمتن و طراحی متریال تیره/روشن.

اپلیکیشن همراه اندروید (APK) از طریق **Capacitor** ساخته می‌شود: [راهنمای ساخت APK](docs/BUILD-APK.md)

---

## ✨ امکانات

- 🏠 **خانه:** فید هوشمند آپدیت‌های موجود، چیپ‌های فیلتر منبع (گوگل‌پلی/کافه‌بازار/مایکت/گیت‌هاب/سیستم)، جستجوی زنده و رادار اسکن با انیمیشن
- ⬇️ **به‌روزرسانی‌ها:** شبیه‌ساز دانلود زنده (درصد، سرعت، توقف/ادامه/لغو)، صف ۳تایی و «به‌روزرسانی همه»
- 🐙 **گیت‌هاب:** مرور مخازن، سینک ریلیز، ستاره/زبان/چنج‌لاگ
- 🕘 **تاریخچه:** گروه‌بندی زمانی (این هفته/هفته گذشته/قدیمی‌تر)، فیلتر موفق/ناموفق، خروجی CSV
- ⚙️ **تنظیمات:** تم تیره/روشن، ۳ رنگ اسکن (سبز/بنفش/آبی)، کنترل منابع و دانلود
- 💎 **درآمدزایی:** اشتراک ویژه (ماهانه/سالانه/مادام‌العمر) با درگاه زرین‌پال/آیدی‌پی، حمایت مالی با دیوار حامیان، تبلیغات بومی حذف‌شونده با عضویت ویژه
- 📱 آنبوردینگ ۳ اسلایدی با توضیح شفاف مجوزها

## 🛠️ تکنولوژی‌ها

| لایه | تکنولوژی |
|------|----------|
| فریم‌ورک | Next.js 16 (App Router) + React 19 |
| استایل | Tailwind CSS 4 + shadcn/ui |

| دیتابیس | Prisma ORM + SQLite |
| اپ اندروید | Capacitor 8 (WebView) |
| فونت | Vazirmatn |

## 🚀 اجرای پروژه

پیش‌نیاز: [Node.js](https://nodejs.org) و ترجیحاً [Bun](https://bun.sh) (یا npm به‌جای آن).

```bash
# ۱. نصب وابستگی‌ها
bun install        # یا: npm install

# ۲. همگام‌سازی دیتابیس (SQLite)
bun run db:push    # یا: npm run db:push

# ۳. اجرای محیط توسعه
bun run dev        # یا: npm run dev
```

سپس در مرورگر: `http://localhost:3000`

دیتابیس با داده‌های نمونه‌ی فارسی (۲۱ برنامه، تاریخچه، حامیان و تبلیغات) در `db/custom.db` همراه مخزن است و به‌صورت خودکار seed می‌شود.

```
└── docs/BUILD-APK.md   # راهنمای ساخت APK
```

## 🌐 انتشار سرور (توصیه‌شده)

آدرس پیش‌فرض داخل APK موقتی است. برای پایداری، وب‌اپ را روی هاست منتشر کنید (مثلاً [Vercel](https://vercel.com)):

1. کد را روی گیتهاب دارید — در Vercel پروژه را Import کنید.
2. دیتابیس SQLite روی سرورهای serverless ماندگار نیست؛ برای نسخه‌ی عملیاتی دیتابیس را به SQLite محلی/فایل روی VPS یا یک دیتابیس ابری منتقل کنید (تغییر `DATABASE_URL`).
3. آدرس نهایی را در `capacitor.config.ts` جایگزین و با `npx cap sync android` دوباره APK بسازید.
