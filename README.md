# 🚀 آپدیت‌یار | UpdateYar

اپلیکیشن فارسی موبایل‌فرست مدیریت به‌روزرسانی برنامه‌ها — **کاملاً آفلاین، بدون نیاز به سرور و اینترنت** — با رابط کاربری راست‌به‌چپ، فونت وزیرمتن و طراحی متریال تیره/روشن.

- 📴 **آفلاین:** کل اپ داخل فایل APK ذخیره می‌شود و بدون اینترنت اجرا می‌شود
- 💾 **داده روی گوشی:** اطلاعات کاربر در حافظه‌ی محلی خود دستگاه ذخیره می‌شود
- 📱 اپلیکیشن اندروید از طریق **Capacitor** ساخته می‌شود: [راهنمای ساخت APK](docs/BUILD-APK.md)

---

## ✨ امکانات

- 🏠 **خانه:** فید هوشمند آپدیت‌های موجود، چیپ‌های فیلتر منبع (گوگل‌پلی/کافه‌بازار/مایکت/گیت‌هاب/سیستم)، جستجوی زنده و رادار اسکن با انیمیشن
- ⬇️ **به‌روزرسانی‌ها:** شبیه‌ساز دانلود زنده (درصد، سرعت، توقف/ادامه/لغو)، صف ۳تایی و «به‌روزرسانی همه»
- 🐙 **گیت‌هاب:** مرور مخازن، سینک ریلیز، ستاره/زبان/چنج‌لاگ
- 🕘 **تاریخچه:** گروه‌بندی زمانی (این هفته/هفته گذشته/قدیمی‌تر)، فیلتر موفق/ناموفق، خروجی CSV
- ⚙️ **تنظیمات:** تم تیره/روشن، ۳ رنگ اسکن (سبز/بنفش/آبی)، کنترل منابع و دانلود
- 💎 **درآمدزایی:** اشتراک ویژه (ماهانه/سالانه/مادام‌العمر) با درگاه زرین‌پال/آیدی‌پی، حمایت مالی با دیوار حامیان، تبلیغات بومی حذف‌شونده با عضویت ویژه
- 📱 آنبوردینگ ۳ اسلایدی با توضیح شفاف مجوزها

## 🛠️ تکنولوژی‌ها

| لایه | تکنولوژی |
|------|----------|
| فریم‌ورک | Next.js 16 (App Router) + React 19 |
| استایل | Tailwind CSS 4 + shadcn/ui |
| وضعیت | Zustand |
| دیتابیس | Prisma ORM + SQLite |
| اپ اندروید | Capacitor 8 (WebView) |
| فونت | Vazirmatn |

## 🚀 اجرای پروژه

پیش‌نیاز: [Node.js](https://nodejs.org) و ترجیحاً [Bun](https://bun.sh) (یا npm به‌جای آن).

```bash
# ۱. نصب وابستگی‌ها
bun install        # یا: npm install

# ۲. همگام‌سازی دیتابیس (SQLite)
bun run db:push    # یا: npm run db:push

# ۳. اجرای محیط توسعه
bun run dev        # یا: npm run dev
```

سپس در مرورگر: `http://localhost:3000`

دیتابیس با داده‌های نمونه‌ی فارسی (۲۱ برنامه، تاریخچه، حامیان و تبلیغات) در `db/custom.db` همراه مخزن است و به‌صورت خودکار seed می‌شود.

## 📁 ساختار پروژه

```
├── src/
│   ├── app/            # صفحات و API Routes
│   │   ├── api/        # apps, scan, history, github, ads, supporters, settings, premium
│   │   └── page.tsx    # شالبوت مرکزی اپ
│   ├── components/     # ۱۴ کامپوننت (HomeView, UpdatesView, GithubView, ...)
│   └── lib/            # persian.ts (تاریخ جلالی/اعداد فارسی), store.ts (Zustand)
├── prisma/schema.prisma
├── db/custom.db        # دیتابیس SQLite آماده
├── android/            # پروژه اندروید آماده (Capacitor)
├── capacitor.config.ts # تنظیمات اپ اندروید
└── docs/BUILD-APK.md   # راهنمای ساخت APK
```

## 🌐 نسخه وب (اختیاری)

اپ به‌صورت استاتیک در پوشه `out/` ساخته می‌شود (`bun run build`) و می‌توانید آن را روی هر هاست استاتیک (Vercel، Netlify، GitHub Pages و…) منتشر کنید — همان تجربه، بدون بک‌اند:

```bash
bun run build   # خروجی: out/
```

> نکته: داده‌های نسخه وب هم در حافظه‌ی مرورگر همان دستگاه ذخیره می‌شود.
