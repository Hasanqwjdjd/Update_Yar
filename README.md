# 🚀 آپدیت‌یار | UpdateYar

اپلیکیشن فارسی موبایل‌فرست مدیریت به‌روزرسانی برنامه‌ها — **با قابلیت‌های واقعی روی گوشی** — با رابط کاربری راست‌به‌چپ، فونت وزیرمتن و طراحی متریال تیره/روشن.

- 📱 **اسکن واقعی:** لیست برنامه‌های نصب‌شده با نام، نسخه، حجم و آیکون واقعی مستقیماً از حافظه‌ی گوشی خوانده می‌شود (پلاگین نیتیو Kotlin/Java + `QUERY_ALL_PACKAGES`)
- 🏪 **اقدام واقعی:** دکمه «آپدیت» صفحه‌ی واقعی برنامه را در کافه‌بازار / مایکت / گوگل‌پلی باز می‌کند؛ دکمه «باز» برنامه را اجرا می‌کند
- 🐙 **گیت‌هاب زنده:** ستاره‌ها و آخرین ریلیز مخازن مستقیماً از `api.github.com` دریافت می‌شود (کش آفلاین دارد)
- 💾 **داده روی گوشی:** همه‌ی تنظیمات و تاریخچه در حافظه‌ی محلی خود دستگاه ذخیره می‌شود؛ هیچ داده‌ای به سرور ارسال نمی‌شود
- 📴 **بدون سرور:** کل رابط کاربری داخل APK ذخیره می‌شود؛ فقط بررسی گیت‌هاب (اختیاری) اینترنت می‌خواهد
- 📱 اپلیکیشن اندروید از طریق **Capacitor 8** ساخته می‌شود: [راهنمای ساخت APK](docs/BUILD-APK.md)

---

## ✨ امکانات

- 🏠 **خانه:** فید برنامه‌های واقعی گوشی (با آیکون‌های اصلی)، چیپ‌های فیلتر منبع، جستجوی زنده و اسکن با انیمیشن رادار
- ⬆️ **به‌روزرسانی‌ها:** تشخیص آپدیت با کاتالوگ مرجع نسخه‌ها + رفتن مستقیم به صفحه فروشگاه
- 🐙 **گیت‌هاب:** مرور مخازن، دریافت زنده‌ی ستاره/ریلیز/چنج‌لاگ از API گیت‌هاب، تشخیص نصب‌بودن روی گوشی
- 🕘 **تاریخچه:** ثبت رویدادهای واقعی (رفتن به صفحه فروشگاه)، گروه‌بندی زمانی، خروجی CSV
- ⚙️ **تنظیمات:** تم تیره/روشن، ۳ رنگ اسکن، کنترل منابع
- 💎 **درآمدزایی:** اشتراک ویژه، حمایت مالی با دیوار حامیان، جایگاه تبلیغات بومی
- 📱 آنبوردینگ ۳ اسلایدی با توضیح شفاف مجوزها

> 🧪 در مرورگر (پیش‌نمایش وب)، چون پلاگین نیتیو در دسترس نیست، داده‌ی نمایشی نشان داده می‌شود — روی گوشی، اسکن واقعی انجام می‌شود.

## 🛠️ تکنولوژی‌ها

| لایه | تکنولوژی |
|------|----------|
| فریم‌ورک | Next.js 16 (App Router) + React 19 |
| استایل | Tailwind CSS 4 + shadcn/ui |
| وضعیت | Zustand |
| دیتابیس | Prisma ORM + SQLite |
| اپ اندروید | Capacitor 8 (WebView) |
| فونت | Vazirmatn |

## 🚀 اجرای پروژه

پیش‌نیاز: [Node.js](https://nodejs.org) و ترجیحاً [Bun](https://bun.sh) (یا npm به‌جای آن).

```bash
# ۱. نصب وابستگی‌ها
bun install        # یا: npm install

# ۲. همگام‌سازی دیتابیس (SQLite)
bun run db:push    # یا: npm run db:push

# ۳. اجرای محیط توسعه
bun run dev        # یا: npm run dev
```

سپس در مرورگر: `http://localhost:3000`

دیتابیس با داده‌های نمونه‌ی فارسی (۲۱ برنامه، تاریخچه، حامیان و تبلیغات) در `db/custom.db` همراه مخزن است و به‌صورت خودکار seed می‌شود.

## 📁 ساختار پروژه

```
├── src/
│   ├── app/            # صفحات و API Routes
│   │   ├── api/        # apps, scan, history, github, ads, supporters, settings, premium
│   │   └── page.tsx    # شالبوت مرکزی اپ
│   ├── components/     # ۱۴ کامپوننت (HomeView, UpdatesView, GithubView, ...)
│   └── lib/            # persian.ts (تاریخ جلالی/اعداد فارسی), store.ts (Zustand)
├── prisma/schema.prisma
├── db/custom.db        # دیتابیس SQLite آماده
├── android/            # پروژه اندروید آماده (Capacitor)
├── capacitor.config.ts # تنظیمات اپ اندروید
└── docs/BUILD-APK.md   # راهنمای ساخت APK
```

## 🌐 نسخه وب (اختیاری)

اپ به‌صورت استاتیک در پوشه `out/` ساخته می‌شود (`bun run build`) و می‌توانید آن را روی هر هاست استاتیک (Vercel، Netlify، GitHub Pages و…) منتشر کنید — همان تجربه، بدون بک‌اند:

```bash
bun run build   # خروجی: out/
```

> نکته: داده‌های نسخه وب هم در حافظه‌ی مرورگر همان دستگاه ذخیره می‌شود.
